## Türkçe

### Açıklama
Game-News-Blog-website, oyun haberlerini yayınlayan ve yönetimini sağlayan basit bir blog/haber sitesidir. Hitit Üniversitesi Bilgisayar Mühendisliği Web Teknolojileri dersi için geliştirilmiş final projesidir. Site Django ile yazılmış ve Bootstrap ile tasarlanmıştır.

### Canlı Site
- Canlı site: https://e-shiro.com

### Özellikler
- Haber ekleme, düzenleme ve silme (admin)
- Kategori yönetimi
- Kullanıcı yorumları
- Haber listesi, arama ve filtreleme
- Basit yetkilendirme (admin / normal kullanıcı)

### Teknolojiler
- Backend: Django
- Frontend: Bootstrap, HTML5, CSS3, JavaScript
- Veritabanı: MySQL

## English

### Description
Game-News-Blog-website is a simple blog/news site for publishing and managing video game news. The project was developed as a final project for the Web Technologies course at Hitit University. The site is built with Django and styled using Bootstrap.

### Live Site
- Live site: https://e-shiro.com

### Features
- Create, edit and delete news posts (admin)
- Category management
- News listing and filtering
- Basic authorization (admin / regular user)

### Technologies
- Backend: Django
- Frontend: Bootstrap, HTML5, CSS3, JavaScript
- Database: MySQL
